## Reference model and real classes

`tests/test_ownership_stateful.py` drives actual AllocationManager/WorkerProxy
classes through pending/granted/cancelled transitions, stale generations,
reordered publications and cancel/grant crossing. PointerLease/scrollbar state is
modeled separately with fresh gestures, outside release, cancellation and stale
context. This avoids treating UI capture as scheduler ownership.

`tests/test_worker_fault_models.py` drives a real local WorkerClient and worker
subprocess. Replaying an identical committed request after a lost acknowledgment
preserves the exact receipt and one task/effect; acknowledgment releases retained
bytes; stale generation results cannot replace the commit. Disconnect preserves
an unacknowledged result. Isolated children exercise truncated writes, SIGSTOP,
SIGKILL, and reaping. These are actual local-process tests, not live scheduler
qualification. Unknown external effects without backend idempotency are not
relabeled successful or retried automatically.

## Exhaustive bounded check

Random stateful sequences can miss rare interleavings. A small independent TLA+
model explores two request generations sharing one recycled numeric job ID,
late grants, transport loss, stale publications and verified terminal evidence.
No fairness assumption forces inaccessible evidence to appear. Ownership-bound
cancellation is explicitly an atomic action in the abstraction; a separate
controller read followed by bare `scancel JOBID` is not justified by the model.

Artifacts: [Ownership.tla](../../../models/allocation/Ownership.tla), safe and
unsafe configurations, and the mapping/assumptions in the adjacent README.

`936a262061c914694dfd669a543be24573c45d5aa0ff20a8b96b23d01e050e88`.

## Findings and recovery integration

The negative counterexample maps to existing reused-placement fixtures and W17
exact token/owner/atomic cancellation regressions. W17 extends this model with
persisted recovery and evidence-driven progress; unknown/missing accounting stays
blocked. The W16 289-test focused run is recorded in W11; W17's initial models
also passed the existing ownership suite. Final integration must rerun after
recovery/readiness edits.

Review fixed a generation setup error in the initial test fixture so stale-result
assertions actually exercise the intended live generation. Independent W17 review
also identified unsupported receipt schemas being interpreted as cleanup authority;
that finding is assigned to its owner for correction and regression evidence.
No orphan PID or bare numeric job ID is used as cancellation authority.

Finite state exploration is neither a proof for every deployment nor a distributed
liveness guarantee. Real atomic filtering qualifications belong to W10/W17, not
to this model. Fault tests and bounded TLC cover complementary obligations.
