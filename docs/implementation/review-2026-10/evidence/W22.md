## Evidence-led scope

The audit records 269 baseline modules, 5,579,640 Python source bytes, 4,741
functions, 591 annotated returns and 320 lines over 200 columns. The review's
329-line count was stale. Static reachability from controller/launch spans 224
modules, demonstrating that a broad directory rename alone would not create a
small independent core. The candidate inventory is a point-in-time integrated
snapshot, not a claim of shipped footprint reduction.

Artifacts: [baseline](W22-architecture-baseline.json) and
[candidate](W22-architecture-candidate.json), reproducible with
`scripts/audit_architecture.py`. They distinguish static conditional imports from
runtime loading and annotate unresolved schema/validator associations.

A mechanical split into seven packages would create extensive import churn
without removing existing cycles. The smallest complete first seam moves the
stdlib-only framing implementation into `raven.transport`, preserves the public
`raven.framing` shim and channel APIs, and updates portable worker digests and
setuptools discovery before introducing subpackages. Other proposed boundaries
remain explicit incremental destinations, not fictitious completed extractions.
W42 can use the graph to select actual core/extension boundaries.

## Command dispatch and developer gates

Six existing low-risk core handlers (export, replay, wrap, bookmark, eval, advise)
now dispatch through the existing canonical command registry's trusted handler
metadata. Controller input parsing, raw expression text, plugin/workbench
precedence, error feedback and action reviews remain in place. No parallel
registry was added. Scheduler-mutating paths were deliberately left in their
characterized owners for later small migrations.

`python scripts/check_quality.py` passes:

- Import-linter: transport cannot import application owners; core command handlers
  cannot directly import controller/scheduler/allocation owners.
- Ruff lint and format checks only for migrated transport/command modules.
- Strict mypy for those boundaries. The explicit `Any` application context in
  command handlers records remaining typing work honestly.

The `partial` marker exists only under `raven.transport`. Package discovery is
`include = ["raven", "raven.*"]`; package data includes the marker. CI's quality
step is coordinated with the qualification owner. Legacy code is not bulk
formatted or claimed fully typed. The documented policy is
[protocol-boundaries.md](../../../guides/protocol-boundaries.md).

The post-extraction command/CLI/benchmark-source/worker-runtime/fault selection
passed 124 tests in 6.51 s. Further registry raw-expression/plugin precedence,

## Final integrated gate commands

The actual CI workflow retains `pytest`, `scripts/check_quality.py`, generated
operation-reference checking, schema/example validation, offline setup, sdist
and wheel builds, installed-command probes outside the checkout, optional
terminal self-test, and release source/inventory policy checks. The concrete
commands are in `.github/workflows/tests.yml`; run its steps against one frozen
source revision and retain the resulting wheel/sdist digests. In particular:

```bash
python scripts/check_quality.py
python scripts/generate_operation_reference.py --check
python scripts/validate_operation_schemas.py
python -m build
```

Then install the built wheel into a fresh environment outside the source
checkout and exercise all three entry points, `doctor`, Heavy `--plan`, fake
reporting, `qualify --offline`, and the optional terminal self-test, as CI does.
Verify that `raven.transport.framing` and its `py.typed` marker occur in both
distributions and that existing public framing imports retain class identity.
The final root-owned release policy check binds those distributions to the
actual delivered revision. This internal gate must close before final delivery;
source-tree import success does not stand in for installation evidence.

Managed Python 3.10.22, 3.11.17, 3.13.16 and 3.14.8 interpreters and editable
`[dev,terminal]` environments were provisioned under `/workspace/raven-compat`,
with a separately scoped UV cache pruned to 9.1 MiB. Interpreter and dependency
inventories are retained as `raw/compat-environments.json` and
`raw/compat-pyVERSION-freeze.txt`. Provisioning is not a compatibility test result;
the root owns the final matrix. The existing 3.12 environment completes the
advertised five-version range.
