# W27 — Role-aware rank log comparison

Source: A-16. Baseline revision `33316a08bd583a242356c7722a21c10e00cff21b`.
The existing bounded log search, normalized two-stream diff, source citations,
and ResearchHub background reader were present. No verified per-rank,
role-cohort first-divergence analysis existed in those paths.

## Design and complete path

The smallest useful extension reuses those paths. `:logdivergence ID ID ...`
selects existing registered logs for the currently connected run. Each source
must start with a bounded producer declaration of exact job/run, rank and cohort.
A declaration is association evidence, not authentication. The UI refuses an
unbound run, changed attempt, unknown catalog ID or duplicate source/rank.
Headers and stable tails are read in the existing worker; paint reads published
results. Source rotation during identity/tail reading rejects that source.

Ordered comparison is independent within declared role cohorts. Conservative
normalization removes the first timestamp and an explicit matching rank prefix;
semantic numeric values remain. The result preserves last common anchor, first
positional disagreement, each raw line and exact file identity. Strict observed
majorities and ties are labelled without declaring correctness. `o` follows the
existing citation path; original bytes/copy/export are unchanged. Refresh retries
read errors without changing the source. Transient rank selections are not saved
as another attempt's preferences.

A simpler normalized pairwise `SequenceMatcher` diff is the comparison baseline.
It is useful for two sources but does not express role cohorts, missing streams,
or ranked consensus and can cost quadratic work on repeated lines. The selected
first-divergence algorithm is O(ranks × retained rows × bounded line length),
with bounded retained-window memory. It deliberately does not reconstruct every
edit or infer causality. Truncated windows need a unique common template anchor;
repeated templates, earlier omitted events, unavailable logs and stream endings
remain explicit. Empty windows abstain.

Limits are 16 ranks, 64 KiB/240 rows per rank, 8192 characters per line and at most
3840 retained templates. Oversized lines fail visibly instead of losing content.
The four available log views and grouping behavior remain unchanged.

## Validation and review

`tests/test_log_divergence.py` covers divergent values, role differences, clock
reordering, majority/tie, repeated templates, truncated anchors, missing streams,
identity mismatch, bounds, asynchronous UI, raw-source drilldown and attempt
invalidation. Existing workbench/search/presentation/responsiveness tests retain
their assertions. Initial combined selection: **163 passed**. Integrated registry,
trace and profiler selection: **102 passed**. Additional empty-window/rotation
regressions passed in the final combined **203-test** selection (5.38 s).

Skeptical review rejected timestamp sorting and blanket numeric masking: either
could conceal meaningful ordering/errors. The UI uses a compact cohort summary
instead of allowing sixteen source headers to displace all useful result rows.
Command registry metadata is explicit; discovery assertions remain unchanged.

## Performance and qualification

`scripts/benchmark_log_divergence.py` compares the same 16-rank, 240-row unique
and repeated-template fixtures with a simple normalized pairwise diff. It checks
the known first disagreement and reports milliseconds, Python allocation peak
and separate whole-process RSS. The acknowledged controlled run on 2026-10-18
measured unique templates at 7.244 → 7.193 ms (0.7% lower) and repeated templates
at 26.800 → 6.452 ms (75.9% lower). Python peaks were 275,041 → 263,641 bytes
and 251,883 → 247,579 bytes respectively; whole-process maximum RSS was
23,168 KiB. The simpler baseline produces more edit operations, so these numbers
compare the stated first-divergence task rather than identical general diff APIs.
Raw results: `W27-measurements.json`; coordinated times and hashes:
`W27-W29-W36-W43-benchmark-window.json`. These are synthetic fixtures, not live
MPI/Slurm qualification.
