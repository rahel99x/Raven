# W24 — Compact recordings and indexed envelopes

Source A-05; baseline `33316a08bd583a242356c7722a21c10e00cff21b`. The existing JSONL archive and exact signature caches were reproduced, not replaced wholesale. W06's captured durable attempt identity is the prerequisite. JSONL remains the default.

The opt-in `blocks-v1` format uses bounded little-endian headers, exact attempt-filename digests, finite JSON array payloads compressed with zlib, SHA-256 checksums and append commit markers. Binary64 values, signed zero, integers, timestamp representation, field order, missing keys and nulls round-trip without numeric coercion. A bounded decoder verifies every frame and returns only the verified prefix before corruption; further appends reject incomplete final commits. Encoded and cumulative decoded byte budgets, nesting/structural limits and finite exponent parsing prevent compressed-input amplification or non-finite smuggling. Explicit recovery copies a verified prefix into a new JSONL file with incomplete coverage and the actual read error; it preserves the damaged source.

A controlled 8,192-sample fixture compared JSONL, simple JSON-array/zlib, an index-pair prototype, fixed three-double arrays and XOR-coded float bits. The pair-index prototype saved only 367 bytes versus framed simple arrays while taking substantially more encoding CPU; it was discarded before publication. Fixed-schema numeric/XOR prototypes were smaller but cannot retain general integers, missing values or metadata without extra representations; their bytes are explicitly not a general-fidelity comparison. The selected format is the simplest general exact array/zlib design. No default-format rollout is justified by these measurements.

Setup exposes preview, explicit copy/verify conversion and persisted format choice, with matching `raven series` CLI commands. Existing JSONL streams keep their format until conversion; changing a preference never triggers hidden bulk work inside an ordinary sample append. New streams use the selected format. An existing compact counterpart remains canonical even if the default later returns to JSONL. Migration uses a private staged copy, verifies all admitted values and a stable source fingerprint, publishes without clobbering an existing compact file, and retains the original JSONL. Read-only or competing state writers cannot publish. Light disk/file quotas include compact files. GPU diagnostics, archive restore, reports, raw exports and installed command routing understand the format.

Interactive bulk work is a named local maintenance subprocess reached through the existing background lane. It has 256 MiB address space, 15 seconds CPU, 20 seconds wall, 64 MiB file-size and bounded request/result limits. The parent retains its persistence lock until the child is reaped; the child inherits the exact state-lock descriptor, so parent death cannot release writer authority while publication continues. Shutdown cancellation kills/reaps the owned child and removes only its exact random staging path. Config persistence remains the small trusted snapshot operation. A remote Heavy worker is unsuitable for local UI-state migration, and no scientific-analysis entitlement follows from this local maintenance path.

`EnvelopeIndex` builds an exact min/max tree over continuous finite samples. Range results retain original extrema order and source indices. Unknown samples, gaps, duplicate timestamps, unsafe arithmetic and interpolated edges use the existing renderer. Existing `SeriesDeque` publications/revisions and full exact signature fallback remain; corrected interior samples invalidate views. Build is O(N), explicit-cadence queries are O(width log N), and inferred cadence adds a one-time median sort. Full UI signature preparation still processes input; the index does not make a frame O(width). Cache cost participates in the existing memory budget. Decompression allocates memory; no mmap/zero-copy claim is made.

Independent review resolved exponent-overflow JSON admission and cumulative decompression amplification. Integration review found a missing managed background-module admission path and an unbounded automatic first-append conversion; the real admission regression and explicit-only conversion rule address both. Fault tests cover truncation, interior corruption, attempt renaming, cancellation, no-clobber output, quota failure, source preservation, schema compatibility, GPU availability, exact signed values and interior correction invalidation. Hypothesis checks compare exact envelope vertices/details with the established renderer and round-trip finite floats/large integers.

## Final regression correction: Quick Advisor and lifecycle fixtures

The integrated discovery gate found four obsolete Quick Advisor fixtures still placing samples in `series/JOBID.jsonl`. They now acquire an actual scoped state owner and bind scheduler submission/start/cluster/restart evidence before creating the exact attempt file. The existing sample-count, unlocked background I/O, bounded-tail and FIFO-refusal assertions remain intact. A separate negative test preserves a legacy file and confirms that its rows are never attributed to the current job.

Review of that consumer also found a real integration gap: its publication key omitted the verified restart token, and a compact recording could be parsed as JSONL and silently contribute no samples. Quick Advisor now captures `SeriesIdentity` with the initial job snapshot, retains that identity through file acquisition, rejects an attempt change with an explicit retry error, and compares the same immutable identity before UI publication. A same-time restart during acquisition and after a worker completes are both covered. The reader discovers compact counterparts even under the JSONL preference and uses the existing verified block decoder. It preserves the detached UI cache, exposes corruption/limited-prefix diagnostics, checks cancellation between frames and caps cumulative decoded bytes before decompression to the Advisor's existing read budget.

Forecast integration fixtures had also mocked `cli.os.getuid` on Python's shared `os` module, inadvertently changing the filesystem trust check's actual UID. The mock is now local to the CLI namespace. Sequential startup tests close their previous session; deliberate malformed-state fixtures are installed offline by a short-lived real owning Store after normal shutdown. Refresh persistence tests flush, close and reopen their actual owners. No production ownership or trust check was relaxed.
