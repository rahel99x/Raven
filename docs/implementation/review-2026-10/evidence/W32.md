# W32 — Bounded phase comparison

Source: B-05, reconciled against baseline `33316a08bd583a242356c7722a21c10e00cff21b`.
Existing analytics and reporting retain measurements but did not implement
phase segmentation or cross-attempt alignment. This is a gated research
prototype. It does not discover scientific phase truth from telemetry alone.

## Design and alternatives

The new explicit measurement contract requires increasing finite times, one
exact attempt per comparison side, selected metrics and matching known units.
Both attempts use reference-derived median/MAD/range normalization. A sorted
union of exact observation timestamps preserves each feature's input index and
original CSV source row; missing data starts a separate block. There is no
interpolation. Bounded binary segmentation precedes phase-summary matching;
matching permits gaps, and only supported matches enter banded DTW with
representative-index downsampling. Caps are 4,096 timestamps, eight features,
32 segments, two million segmentation work units and 200,000 DTW cells.

Fixed equal windows plus linear time mapping are the simpler baseline. They
are much cheaper but cannot adjust known shifted boundaries; raw unconstrained
DTW would force endpoint correspondences and can require quadratic work.
PELT was not selected or described as universally linear. The implementation
reports gaps, insufficient observations and uncertain/constant alignment.
A numerical match does not establish that two scientific phases are equivalent.

The existing Research operation `phase-alignment` provides Original/Aligned
views with identical underlying results, untouched source files and original
timestamps. Capture digests, source paths/selectors, original CSV rows and input
sample indices remain distinct. The converter and schemas reuse W23's exact
source/attempt selection. Actual worker admission and cancellation use the
existing Heavy operation boundary; no new executor or toolbar is introduced.

## Validation and results

The 131-test focused command recorded in W26.md includes source fidelity,
missing blocks, unrelated signals, constant abstention, cancellation/bounds,
unit/identity errors, reversible views and an actual WorkerClient path.

`W26-W32-evaluation.json` records 20 held-out synthetic phase fixtures, seeds
2000–2019, with independent noise, changed phase lengths and 1.5× time scaling.
Mean boundary error is **0 samples**, versus **6.675 samples** for fixed windows.
Mean phase-progress alignment error is **0.01451** of phase progress. False
phase correspondences are **0**, versus **9.948%** for linear time mapping.
The unrelated-signal fixture produced no aligned pairs. These favorable
controlled results do not qualify unseen scientific workloads.

The harness also executes the repository's actual reporting calculation
locally and captures measured timestamps and numerical errors: 32 samples from
one declared solve phase produce **two statistical segments**. This is a
recorded negative semantic result: convergence changes are not extra ground
truth phases. No live Slurm, GPU or cluster performance claim is made.

Controlled scaling used fresh processes with fixed source hashes, three timing
repetitions and separate Python allocation measurements:

| Samples × features | Median alignment | Python peak | Whole-process RSS |
| --- | ---: | ---: | ---: |
| 128 × 1 | 5.856 ms | 393,090 B | 14,848 KiB |
| 512 × 4 | 21.048 ms | 915,378 B | 17,652 KiB |
| 1,024 × 8 | 73.432 ms | 2,914,706 B | 27,760 KiB |

Fixed windows take roughly 1.75–2.19 µs and 120–280 Python bytes on these
fixtures. That substantial cost difference is disclosed: fixed windows offer
a different, simpler capability. Raw CPU timings, segmentation work and DTW
cells are in `raw/W26-W32-*.json`; process RSS includes fixtures and other
algorithms and must not be confused with Python allocation peaks.

Independent review found loss of original CSV row provenance in an early
adapter. It now preserves complete source metadata and distinguishes original
source rows from input positions, with a real export/index regression. No
source values are rewritten for attractive aligned output.

## Qualification decision

Ship only as explicitly experimental. The vertical prototype, known-phase
baseline, local reporting example, synthetic held-out evaluation and uncertainty
report are complete. **Product release is blocked** on a representative,
authorized held-out corpus with independently supplied scientific phase labels,
useful boundary/alignment performance and false-correspondence review. It is
not acceptable to substitute synthetic labels or this one reporting example
for that evidence. Final integrated regression and packaging remain root-owned.
