## Existing acceptance criteria preserved

The five journeys were located in `docs/QUALIFICATION.md` §5, not invented:
find a running job; diagnose a failed job; inspect results; connect a project;
prepare a reviewed rerun. The archived flagship strategy G5 proposes at least
80% unaided task completion. No participants have completed these tasks in this
implementation task, and no population claim is made.

## Complete preparation path

`scripts/prepare_usability_study.py --output NEW_DIRECTORY` reuses the existing
project template and actual small CPU experiment, prepares successful and failed
local launches using the same background launcher as the UI, checks their
retained states and stdout, opens exact-attempt Run home reports and verifies a
rerun review without submitting it. The scheduler demonstration remains the
explicit FakeBackend. A manifest binds source revision/content hashes and
fixture bytes; task cards and an empty observation CSV contain no fabricated
participant outcomes.

The observation columns cover completion, unaided success, seconds, unnecessary
decisions, documentation lookups, error recovery, account/resource understanding,
observer assistance and accessibility. The [study guide](../../../guides/usability-study.md)
requires consent, pseudonyms and separation of demonstration and real-account
sessions. It preserves the five-participant plan and the stop-before-submit demo
boundary. A lab account is never selected or charged by this preparation script.

The simpler alternative, a prose checklist only, would not establish that the
provided launch/recording/review fixtures actually work. Reusing existing APIs
avoids a parallel study-only launcher and makes failure observable. Preparation
has a new-directory requirement, a bounded CPU example and ten-second local
outcome observation budgets; it does not collect credentials or private data.

## Validation and skeptical review

The preparation was rerun end to end in `/tmp/raven-g5-final-fixture-1`; its
revision and content-bound manifest is [W44-preparation.json](https://github.com/rahel99x/Raven/blob/evidence/pre-review-2026-10-20/docs/implementation/review-2026-10/evidence/W44-preparation.json). The CPU
example completed, separate local runs reached COMPLETED and FAILED (exit 7),
their actual stdout was retained, and both exact-source rerun reviews remained
local. An earlier foreground-launch preparation exposed empty retained logs
(foreground CLI intentionally preserves streams); it was corrected to reuse
`start_local_plan`, the existing UI path, before recording preparation success.
No product assertion was weakened.

No human task time, task completion rate, error-recovery success, participant
account comprehension or usability gain has been measured. Script execution is
not a substitute. The blocker is independent consenting participants and
authorization to recruit/contact them; the real-account phase additionally
requires site/account access and an explicit compute budget. Once unblocked,
run the five exact journeys, rank observed friction, ship focused fixes and
repeat affected tasks with practice effects disclosed. Preserve negative results.
